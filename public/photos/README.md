# 📸 Le vostre foto

Metti qui le foto del gioco. Nomi file suggeriti (già collegati in `content.config.ts`):

| File | Dove appare |
|---|---|
| `foto-livello-01.jpg` | Ricordo di fine livello 1 |
| `foto-livello-03.jpg` | **Puzzle del livello 3** (meglio se quadrata, min 600×600) |
| `foto-livello-07.jpg` | Sotto la patina della scratch card (livello 7) |
| `foto-livello-16-prima.jpg` | Slider prima/dopo — lato "prima" |
| `foto-livello-16-dopo.jpg` | Slider prima/dopo — lato "dopo" |

Puoi aggiungere una foto al ricordo di **qualsiasi** livello: basta impostare
`memoryPhoto: "/photos/nome-file.jpg"` nel livello corrispondente in
`content.config.ts`.

Se una foto non c'è, il gioco mostra un segnaposto elegante e non si rompe.
